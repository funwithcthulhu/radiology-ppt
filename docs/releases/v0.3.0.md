# Radiopaedia Case PowerPoint Builder v0.3.0

Release for export hardening, Core Review import fixes, search improvements, and clearer desktop controls.

## Changed

- Improved random Radiopaedia search for modality requests such as MRI and raised the desktop per-row request limit to 100.
- Added a progress-panel abort control so an active generation/import/export job can be cancelled from the visible activity view.
- Reduced immediate inline grid validation styling while keeping request validation messages and generate-time validation.
- Improved Core Review source imports, including PDF image-question extraction and rejection of unsupported binary sources in the Cases importer.
- Added AI-boundary documentation describing optional local Ollama use, user review points, local data handling, and known failure modes.

## Fixed

- Validated PowerPoint export inputs before rendering, including missing case data, missing images, unsupported image paths, and invalid output paths.
- Wrote PowerPoint outputs atomically to avoid corrupting an existing output if generation fails.
- Cleaned up export staging files after failed exports and preserved distinct images with duplicate basenames.
- Improved backend error messages around invalid export inputs and backend exits.
