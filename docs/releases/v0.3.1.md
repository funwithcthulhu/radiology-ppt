# Radiopaedia Case PowerPoint Builder v0.3.1

Patch release for random case discovery and case-conference slide cleanup.

## Changed

- Broadened random Radiopaedia case search so broad modality requests, such as MRI, build a deeper candidate pool before selecting cases.
- Added system-filtered Radiopaedia search fan-out for broad random modality requests so the app can reach more than the first global modality result window.
- Stopped probing beyond the discovered Radiopaedia search page range when paginated results end.
- Simplified the desktop case request grid by removing the guidance column, hiding the diagnosis box for random rows, and moving lower-priority filters into selected-row details.

## Fixed

- Removed diagnosis-bearing Radiopaedia case URL slugs from unrevealed image-slide attribution while preserving neutral attribution fields.
